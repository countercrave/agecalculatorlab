What this result means

A useful answer includes both the number and its assumptions.

Calculation method

Inclusive Date Count Calculator calculates the number of calendar days with explicit start- and end-date inclusion using Gregorian calendar arithmetic. Dates are treated as date-only values, avoiding accidental time-of-day and daylight-saving shifts.

Important: Weekend, holiday, legal, medical, financial, school or workplace policies are included only when the tool explicitly asks for them. Confirm official decisions with the responsible authority.

Common checks

  • Check whether endpoints should be included.
